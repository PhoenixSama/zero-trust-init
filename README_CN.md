# Modern Debian 零信任初始化脚本 (Zero-Trust Init) 🚀

*阅读其他语言版本: [English](README.md)*

---

## 这是什么？
**Zero-Trust Init** 这是一个专为 **现代 Debian (12/Bookworm, 13/Trixie 及更高版本)** 打造的高度定制化、具备企业级容错和零日防御能力的系统初始化脚本。它专为喜欢极简安装并追求对 VPS 环境进行“零信任”极致控制的极客设计。

## 一键执行指令
在终端中运行以下命令即可直接下载并执行脚本（需要 `curl`）：

```bash
bash <(curl -sL https://raw.githubusercontent.com/PhoenixSama/zero-trust-init/main/init.sh)
```
*（注意：由于脚本包含底层的内核调优和防断网 SSH 隔离策略，请务必在可靠的本地终端中执行。）*

## 核心特性
*   **动态全代号镜像路由：** 自动探测服务器地理位置与 Debian 版本代号，无缝注入最快的本地软件源。
*   **自适应 ZRAM 内存调度：** 通过嗅探 CPU 核心数和现代矢量指令集（AVX/ASIMD），动态分配最匹配的压缩算法（`lz4` 或 `zstd`）。
*   **坚如磐石的边界防御：** 自动防碰撞的随机高位 SSH 端口、非标准私钥架构、UFW 智能联动 Fail2ban，以及防锁死的绝对闭环回滚机制。
*   **0-Day 提权漏洞泛化防御：** 针对实战级本地提权漏洞（如 Copy Fail 等），实施严格的纵深防御与非特权用户隔离。
*   **现代 Sysctl 调优：** 彻底解除系统文件句柄上限，全面启用 BBR 拥塞控制和 FQ 排队规则。
